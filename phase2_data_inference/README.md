# Phase 2 - Data & Inference

Statistics + Sampling Theory.  Eight to ten weeks in the roadmap.

Probability (Phase 1) says what to expect in theory.  Statistics says
what the data actually shows and how confident to be about it; sampling
theory says what any dataset truly represents.  Both are needed before
interpreting empirical data honestly.
